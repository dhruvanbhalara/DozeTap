# Contributing to DozeTap

Thank you for your interest in contributing to DozeTap!

## How to Contribute

1. **Fork the Repository**: Create your own fork of `DozeTap`.
2. **Create a Feature Branch**: `git checkout -b feature/amazing-feature`
3. **Commit Your Changes**: Follow clear commit messages.
4. **Ensure Tests Pass**: Run `./gradlew test` before submitting.
5. **Open a Pull Request**: Submit your PR with a clear summary of your changes.

## Code Style & Architecture Guidelines
- Follow **Clean Architecture** (Domain -> Data -> UI).
- Strictly adhere to **SOLID principles**.
- Use **Jetpack Compose** for all UI components.
- Do NOT add proprietary dependencies (must stay 100% open-source for F-Droid).

Thank you for helping make DozeTap better!
